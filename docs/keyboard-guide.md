# Keyboard reference

These are the default bindings. Settings can override them, and command hints reflect the active bindings. A browsing shortcut applies to its current surface; normal typing stays with a focused editor.

## Open Shelf globally

Control + Option + T shows or hides the shelves by default. Settings also offers separately recorded global shortcuts for Library, shelf search and copying the latest image. Check whether a shortcut is Off before expecting it to work from another app.

## Move around shelves

Arrow keys move the selection. Tab and Shift + Tab switch shelves. Command + Left or Right moves to the first or last item; Option + Left or Right changes pages. Number keys 1 through 9 select visible quick-selection slots.

## Preview and copy

Space previews the selected item. Command + C or Return copies while browsing. Command + Return requests direct paste into the previous app and needs Accessibility permission; ordinary copy does not. In a text preview, Command + Return finishes an active edit.

## Keep and file items

P pins an item, Shift + P opens pin-to-folder, and Option + P opens name-and-pin. F toggles pinned-only browsing. Use these commands outside text fields so the letters are treated as actions.

## Take down or trash

On a shelf, S takes down an item and Backspace undoes the latest take-down. In Library, S moves the selection to Trash and Backspace or Command + Z undoes the latest recoverable move. Check the current surface before using S.

## Search the current surface

Shift + S searches shelves. In Library, Command + F searches the current view, while Command + 0, 1, 2 and 3 select all types, images, texts and links respectively. Command + K opens searchable Actions.

## Move focus in Library

F6 or Control + Tab moves to the next pane. Shift + F6 or Control + Shift + Tab moves back. Shift with arrow keys extends selection, and Command + A selects all in the current browsing context.

## Pick a markup tool

In image markup, V selects annotations, B chooses pen, H marker, R rectangle, O ellipse, A arrow, D line and T text. C enters crop mode. While cropping, Return applies and Escape cancels the crop.
