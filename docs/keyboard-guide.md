# Keyboard reference

These are the default bindings. Settings can override them, and command hints reflect the active bindings. A browsing shortcut applies to its current surface; normal typing stays with a focused editor.

## Open Shelf globally

Control + Option + T shows or hides the shelves by default. Settings also offers separately recorded global shortcuts for Library, shelf search and copying the latest image. Check whether a shortcut is Off before expecting it to work from another app.

## Move around shelves

Arrow keys move the selection. Tab and Shift + Tab switch shelves. Command + Left or Right moves to the first or last item; Option + Left or Right changes pages. Number keys 1 through 9 select visible quick-selection slots.

## Preview and copy

Space previews the selected item. Command + C or Return copies while browsing. Command + Return requests direct paste into the previous app and needs Accessibility permission; ordinary copy does not. In a text preview, Command + Return finishes an active edit.
