# Using the Library

Open Library to organize copies, search a collection and recover removed items. The toolbar contains view controls, filters, sorting, search and Actions.

## Check the current scope

Recent copies, saved content, folders and Trash show different sets of records. Before searching for a missing item, check the selected sidebar scope and any pinned-only or type filters.

## Choose grid or list

Use the grid and list buttons in the toolbar to change presentation. The inspector button shows or hides details for the inspected item. The sidebar and content area can be resized to suit the window.

## Sort the current view

The Sort menu offers newest first, oldest first, title, reverse title, last copied and best match. When checking search results, consider both the query and the selected sort order.

## Keep a record

Use **Save to library** from More, pin the selection, or organize it with a folder or tag. These retained records are kept when ordinary unsaved history expires. Pinning also makes an item available in the pinned-only view.

## File items together

Create a folder with Command + Shift + N. Select records and choose **Add to folder** from More. On a shelf, Shift + P opens the pin-to-folder picker. A Library folder is an organizational collection, not a Finder destination.

## Add a tag

Select a record and choose **Add tag…**, or use Command + Shift + T in Library. Tags help retrieve related content without relying on the copied text or website title.

## Write a note

Command + N creates a note in Library. Click text in its preview to edit it. Finish editing with Command + Return before using browsing commands; ordinary typing and text-editing shortcuts belong to the editor.

## Export a copy

Choose **Export copies…** or press Command + Shift + E. Text exports as UTF-8 text and links as web-location files. Exports are separate snapshots: later changes in Shelf do not rewrite an exported copy.
