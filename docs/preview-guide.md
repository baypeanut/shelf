# Previews and editing

Space opens a preview of the selected item. Image, text and link previews share native macOS window controls while offering tools appropriate to their content.

## Close or minimize

The red close, yellow minimize and green zoom controls are at the top left. Closing a preview closes that window; Shelf can continue running in the menu bar. A save failure opens a recovery sheet before the draft is discarded.

## Edit copied text

Click the text to begin editing. Changes save automatically, and Command + Return finishes editing. Watch the status message for save errors before leaving the preview. The text editor keeps normal selection, typing and undo behavior.

## Annotate an image

Use **Image markup** or the default M browsing shortcut. The toolbar offers a selection tool, pen, marker, rectangle, ellipse, arrow, line and text. Select an existing annotation to work on it.

## Adjust annotation style

The color control changes annotation color. **Annotation style** provides stroke width, shape fill and text size controls. These controls affect annotation appearance; they do not change the dimensions of the source image.

## Crop an image

Enter crop mode with the crop button or C while browsing an image. Adjust the crop area and use the checkmark or Return to apply it. Escape cancels the active crop, and **Reset crop** restores the crop boundary.

## Undo an edit

The markup toolbar provides Undo and Redo. Command + Z undoes a markup change and Command + Shift + Z redoes it. Check the active editor before using undo, since text editing and Library Trash have their own undo actions.

## Keep the original

Image markup and cropping preserve the original image while producing an edited representation. Verify an exported or copied image when its final dimensions matter, especially after applying a crop.

## Copy recognized text

Use **Copy text from image** or Command + Shift + C from a shelf, Library or image preview. Recognition runs locally. Its usefulness depends on the legibility and language of the image; inspect the copied text before relying on it.
